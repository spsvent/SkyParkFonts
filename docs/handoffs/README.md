# Handoffs

Before stopping work on a branch, update one file here. Replace branch slashes with
hyphens: `chore/101-github-workflow-baseline` becomes
`chore-101-github-workflow-baseline.md`.

```markdown
# <branch name>

**Goal:** One-line purpose and issue link.
**Done:** Verified changes, relevant files, commit/PR links.
**Next:** The next concrete action and who owns it.
**Verify:** Actual commands or click-paths and observed results.
**Gotchas:** Auth, environment, production boundaries, unresolved limitations.
```

Do not include credentials or guest data. Keep the note current and distinguish
proposed work, merged code, and deployed behavior.
